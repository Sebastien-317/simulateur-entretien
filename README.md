# Simulateur d'entretien

Simulateur d'entretien d'embauche avec un recruteur IA (API DeepSeek), pour préparer les étudiants en recherche d'alternance ou de stage.

- Le recruteur présente le poste, pose ses questions une par une (fonctionnelles, techniques, mises en situation, RH) et relance si la réponse est floue.
- Réponses à l'oral (transcription DeepSeek) ou à l'écrit ; voix du recruteur assurée par l'appareil.
- Compte-rendu final : note, scores par catégorie, réponses idéales, plan d'action, coût de la séance.

Page unique (`index.html`), sans serveur : la clé API DeepSeek est saisie dans la page et reste dans le navigateur.
