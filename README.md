# Simulateur d'entretien

Simulateur d'entretien d'embauche avec un recruteur IA (Gemini, gratuit, ou DeepSeek), pour préparer les étudiants en recherche d'alternance ou de stage.

- Le recruteur présente le poste, pose ses questions une par une (fonctionnelles, techniques, mises en situation, RH) et relance si la réponse est floue.
- Réponses à l'oral (transcription par le moteur IA choisi) ou à l'écrit.
- Voix du recruteur au choix : basique (appareil, gratuite), Google Chirp 3 HD ou ElevenLabs (clés à saisir dans la page).
- Compte-rendu final : note, scores par catégorie, réponses idéales, plan d'action, coût de la séance.

Page unique (`index.html`), sans serveur : les clés API sont saisies dans la page et reste dans le navigateur.
